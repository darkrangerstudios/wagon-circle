# Choose where the work happens

Each agent has its own working session. The room is where you ask questions, see results and coordinate help.

Select a new session or an available existing one. A fork creates a separate conversation. Continue is available only when the session can be safely resumed without competing with another writer. Check the selected project and execution host.

Session-history sharing is separate from selecting a working session. Imported history starts private. When supported and enabled, another participant can retrieve relevant passages as reference; old requests do not start new work. Changing sessions requires renewed sharing access.

Capabilities vary by provider and session. An unavailable control does not become available just by choosing Work mode.
