How it works

Wagon Wheel is a VS Code extension. It starts Claude Code and Codex as its own private child processes and sits between them, deciding who hears what.

Routing

Mention to talk

@claude, @codex or @both. When one agent starts a line with @ the other, the room hands the work across, up to a hop cap you set per message so they can't loop forever. Agreeing with @codex in passing is just conversation.

Context

Everyone stays caught up

Each agent receives exactly what it missed since its last turn, labelled by speaker, and never its own words back. Agent text always arrives marked as relayed, so neither model mistakes the other for you.

Memory

Fork, never share

Bring in an existing Codex thread, an existing Claude Code session, or both. Each is forked, so each agent keeps its full memory and your originals are never touched. Each side's recent history briefs the other, read from disk with no model call.

Visibility

Watch them work

Live status for each agent: thinking, the file it's reading, the command it's running, then writing, with a timer. The thinking text is one click away, and every answer keeps its trail of steps.

Files

Bring your files

Paste a screenshot, drop in a log, attach a spec. Images reach both agents as real image input; Markdown, code and data are read inline; PDFs and big files are passed for the agents to open. Whoever missed them gets them on their next turn.

Security

Nothing faces out

The agents talk to the room over stdio, private pipes with no address to dial: no daemon, no localhost port, no web server. Both run read-only by default, and the room blocks quota-credit spending, logout and deletes outright.

Cheap to keep talking

Each agent keeps one long-lived session, and the room sends only new lines. Project instructions load once; after that, earlier context is re-read from the provider's prompt cache at a fraction of the price. Here are the same four turns on Claude Sonnet, both ways:

Get started

Wagon Wheel is an early prototype and isn't on the VS Code Marketplace yet. Run it from source:

  1. Have both CLIs signed in

    Install Claude Code and the Codex CLI, and sign each in to your own subscription. Wagon Wheel uses them as-is.

  2. Clone the repo

    git clone https://github.com/darkrangerstudios/wagon-circle.git

  3. Launch it in VS Code

    code --extensionDevelopmentPath="$PWD/wagon-circle" --new-window

    Then run Wagon Wheel: New Room or Wagon Wheel: Join Existing Conversations from the Command Palette. Set wagonWheel.userName if the agents should know you by a different name.
